# ReStory: Chill Electronics Repairs Wiki

[Visit ReStorytips](https://www.restorytips.com/)

ReStorytips is an independent fan-made wiki for *ReStory: Chill Electronics Repairs*. The site organizes repair walkthroughs, device and parts notes, story choices, achievements, settings, and known issues.

This repository contains the Next.js source for the multilingual guide website.
