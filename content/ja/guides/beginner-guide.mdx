# リ・ストーリー: 思い出修理屋 — 初心者ガイド

『リ・ストーリー: 思い出修理屋』では、2000年代半ばの東京で小さな電子機器修理店を経営します。ここでは確認済みの基本ループをまとめ、未確認の内容は **待確認** としています。

## 修理店の基本ループ

<RepairStep number="01" title="お客さんの依頼を受ける">
  お客さんとの会話と修理依頼から仕事が始まります。選択によって店や登場人物の物語が変化します。
</RepairStep>

<RepairStep number="02" title="デバイスを分解する">
  公式説明で確認できる流れは、分解、クリーニング、故障部品の交換、再組み立てです。
</RepairStep>

<RepairStep number="03" title="清掃して部品を交換する">
  店の道具を使い、Y2K時代のウェブブラウザで交換部品を調べます。完全な部品一覧は **待確認** です。
</RepairStep>

<RepairStep number="04" title="再組み立てと店の管理">
  デバイスを組み直し、お金を管理しながらお客さんの物語を進めます。メインストーリーは15時間以上で、分岐があります。
</RepairStep>

<Callout title="確認できていること" tone="teal">
  Mandragora と tinyBuild による、物語重視の居心地のよい修理店シミュレーションです。フル版はSteamのWindowsとmacOSに対応し、Steam DeckではPlayableと表示されています。
</Callout>

エンディング数や隠し実績の条件は **待確認** です。フル版には50個のSteam実績があります。
