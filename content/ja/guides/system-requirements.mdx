『リ・ストーリー: 思い出修理屋』のWindows最低要件は、Win10 x64、2コア/4スレッドCPU、4GB RAM、GTX 750ti、DirectX 11、1GBのストレージです。macOSについてSteam公式ストアは、macOS 14以降、Apple M1、8GB RAM、M1のApple統合GPU、1GBのストレージを示しています。

## Windowsの最低要件

Steamの製品版ページには、次のWindows最低要件が掲載されています。推奨設定や固定フレームレートの保証ではありません。

| 項目 | Windows最低要件 |
| --- | --- |
| OS | Win10 x64 |
| CPU | 2コア / 4スレッドCPU |
| メモリ | 4GB RAM |
| GPU | GTX 750ti |
| グラフィックAPI | DirectX 11 |
| ストレージ | 1GBの空き容量 |

Demoページにも、Win10 x64、2コア/4スレッド、4GB RAM、GTX 750ti、1GBという基本的なWindows要件があります。Demoと製品版の公開ベースラインが重なることは確認できますが、後のパッチでも性能が同じだとは限りません。

## macOSの最低要件

Steamストアによると製品版はmacOSに対応します。最低表ではmacOS 14以降、Apple M1、8GB RAM、M1のApple統合GPU、1GBの空き容量が必要です。Appleプロセッサも必要とされています。

macOSでは公式の最低表を基準にし、インストール前にMacのモデルとOSを照らし合わせてください。

  提供された資料には、WindowsとmacOSについて上記の公式最低要件が掲載されています。
</Callout>

## ストレージとインストールの注意

公式の最低表では、WindowsとmacOSのどちらも1GBの空き容量が必要です。これは公開された必要容量であり、パッチの増加、シェーダーキャッシュ、セーブのバックアップ、Steam本体の容量までは保証しません。発売後に測ったインストールサイズを追加する場合は、別の情報として日付を付けます。

DemoのWindows専用表を製品版のMacページにコピーしないでください。macOS対応とAppleプロセッサ要件は製品版が根拠です。Windows要件が重なっていても、Demoが製品版の現在のシステムページの代わりになるわけではありません。

具体的な環境のプレイヤーは、ハードウェアを最低表と比較し、非公式ベンチマークではなくSteam公式の返品・サポート方針を利用してください。
