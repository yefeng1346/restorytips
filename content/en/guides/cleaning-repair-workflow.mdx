# Cleaning & Repair Workflow

The official description gives ReStory's repair loop in a clear order. Use this page as the high-level workflow for every customer order.

<RepairStep number="01" title="Disassemble">
  Take the nostalgic device apart so its faulty components can be inspected.
</RepairStep>

<RepairStep number="02" title="Clean">
  Clean the device and its components with the available shop tools.
</RepairStep>

<RepairStep number="03" title="Replace faulty parts">
  Research and source spare parts through the Y2K-era browser.
</RepairStep>

<RepairStep number="04" title="Reassemble">
  Put the device back together, then continue the customer order and shop-management loop.
</RepairStep>

<Callout title="Workflow overview" tone="gold">
  This page records the high-level sequence: disassembly, cleaning, faulty-part replacement, reassembly, and delivery.
</Callout>
