## VSync and target framerate

The official performance playtest patch discusses VSync and target framerate. Its practical note is to disable VSync when a performance problem appears and set the target to 30 or 60.

## Resolution and window mode status

Steam Community discussions include topics about Resolution Changes and Windowed Fullscreen. Use the current game settings and official store information when checking a display issue.

## Ultrawide considerations

The official full-release issue notes mention an UltraWide problem while disassembling devices. Record the device, resolution, and build if the behavior is reproduced.

An ultrawide troubleshooting card should state that disassembly may be affected and link to the official issue notes.

## A safe troubleshooting record

When a player reports a resolution or frame problem, capture platform, display resolution, window mode, VSync state, target frame rate, and the affected repair action. This turns a vague “settings do not work” report into a reproducible note. It also keeps Steam Deck compatibility discussions separate from Windows or Mac settings.

If the issue is a device stuck during disassembly, link to the Cleaning and Controller pages only when the observed symptom matches their scope. Do not treat an ultrawide problem as a controller problem or a community topic as an official fix.
