The minimum system requirements for ReStory: Chill Electronics Repairs are Win10 x64, a 2-core/4-thread CPU, 4 GB RAM, a GTX 750ti, DirectX 11, and 1 GB storage on Windows. On macOS, the official store lists macOS 14 or newer, an Apple M1 processor, 8 GB RAM, Apple integrated GPU on M1, and 1 GB storage.

## Windows minimum requirements

The official full-game Steam page lists the following Windows minimums. These are minimum requirements, not a recommended preset or a guarantee of a fixed frame rate.

| Component | Windows minimum |
| --- | --- |
| Operating system | Win10 x64 |
| CPU | 2-core / 4-thread CPU |
| Memory | 4 GB RAM |
| GPU | GTX 750ti |
| Graphics API | DirectX 11 |
| Storage | 1 GB available space |

The Demo page lists the same basic Windows minimum profile: Win10 x64, 2-core/4-thread CPU, 4 GB RAM, GTX 750ti, and 1 GB storage. That overlap confirms the published baseline between the Demo and full-release Windows pages, but it does not prove that every later patch keeps identical performance.

## macOS minimum requirements

The full release supports macOS according to the Steam store. Its minimum table lists macOS 14 or later, Apple M1, 8 GB RAM, Apple integrated GPU on M1, and 1 GB available storage. It also states that an Apple processor is required.

The official minimum table is the appropriate baseline for macOS. Compare your Mac model and operating system with those published requirements before installing.

## Storage and installation context

The official minimum tables list 1 GB of available storage for both Windows and macOS. This is the published free-space requirement, not a promise about patch growth, shader cache, save backups, or the space needed by Steam itself. Keep any post-launch installation-size measurement separate and date it if one is added later.

The Demo’s Windows-only minimum table should not be copied onto the full Mac page. The full release is the source for macOS support and the Apple processor requirement. Similarly, the Windows overlap does not make the Demo a substitute for the full game’s current system page.

Players with an exact setup should compare their hardware with the minimum table and use the official Steam return and support policies available on the store rather than relying on an unofficial benchmark.
